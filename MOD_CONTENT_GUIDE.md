## 🪨 ORES & MINING

### Standard Ores (Furnace Smelting)

#### **Bauxite**
- **Location**: Overworld (Y: -16 to 128)
- **Tool Required**: Iron Pickaxe
- **Hardness**: 1.0
- **Generation**: 7 veins per chunk, 9 ore per vein
- **Replaces**: Stone ore replaceables, Deepslate
- **Smelts Into**: Aluminum Ingot
- **Uses**: Core material for machine frames

#### **Cassiterite Ore**
- **Location**: Overworld (Y: -32 to 96)
- **Tool Required**: Iron Pickaxe
- **Hardness**: 1.0
- **Generation**: 6 veins per chunk, 7 ore per vein
- **Replaces**: Stone ore replaceables
- **Smelts Into**: Tin Ingot
- **Uses**: Alloys and crafting components

#### **Galena Ore**
- **Location**: Overworld (Y: -48 to 48)
- **Tool Required**: Iron Pickaxe
- **Hardness**: 1.0
- **Generation**: 4 veins per chunk, 6 ore per vein
- **Replaces**: Stone ore replaceables
- **Smelts Into**: Lead Ingot
- **Uses**: Arrows, ammunition

#### **Cinnabar Ore**
- **Location**: Deep Overworld (Y: -64 to -8)
- **Tool Required**: **Diamond Pickaxe**
- **Hardness**: 1.0
- **Generation**: 3 veins per chunk, 4 ore per vein
- **Replaces**: Stone ore replaceables
- **Smelts Into**: Mercury Ingot
- **Uses**: Advanced chemistry, special recipes

#### **Ilmenite Ore**
- **Location**: Overworld (Y: -64 to 16)

### The Crusher

#### **Crusher Block**
- **Type**: Processing Machine
- **GUI**: Yes (CrusherGUI)
- **Inventory**: Input + Output slots
- **Power**: None (manual processing)
- **Recipe**: Requires Machine Frame + other components

**Crusher Recipes:**
1. **Iron Ingot + Charcoal → Steel Powder**
   - Input Slot 0: Iron Ingot
   - Input Slot 1: Charcoal
   - Output Slot 2: Steel Powder

2. **Glass Block → Silicon Dust**
   - Input Slot 0: Glass Block
   - Input Slot 1: Empty
   - Output Slot 2: Silicon Dust

**Processing Logic:**
- Checks for correct inputs
- Verifies output slot has space (<64)
- Removes 1 of each input
- Adds 1 output
- Manual operation (click-based)

### The Refinery

#### **Refinery Block**
- **Type**: Multi-Output Processor
- **GUI**: Yes (RefineryGUI)
- **Inventory**: 2 inputs + 4 outputs
- **Power**: None
- **Recipe**: Machine Frame + Steel Ingots + Titanium Ingots + Crude Oil Bucket + Campfire

**Refinery Recipe:**
- **Input Slot 0**: Coal
- **Input Slot 1**: Crude Oil (bucket)
- **Output Slot 2**: Propane (x1)
- **Output Slot 3**: Gasoline (x1)
- **Output Slot 4**: Diesel (x1)
- **Output Slot 5**: Asphalt (x1)

**Processing Logic:**
- ALL FOUR outputs produced simultaneously
- Checks all output slots have space (≤63)
- Can output to existing stacks or empty slots
- Removes coal + oil bucket
- Returns empty bucket

## 📜 COMPLETE CRAFTING TREES

### Machine Production Path

```
1. Mine Bauxite → Smelt → Aluminum Ingot
2. Mine Iron Ore → Smelt → Iron Ingot
3. Make Charcoal from logs
4. Craft CRUSHER:
   └─ [Base Crusher Recipe] + basic materials

5. Use Crusher: Iron Ingot + Charcoal → Steel Powder
6. Blast Furnace: Steel Powder → Steel Ingot

7. Craft Steel Beams (from Steel Ingots)
8. Craft Steel Face Plate (from Steel Ingots)
9. Craft Steel Frame (Steel Beams + Steel Face Plate)
10. Craft Machine Frame (Steel Frame + Aluminum Ingots)

11. Now you can craft:
    - Refinery (Machine Frame + Steel + Titanium + Crude Oil Bucket + Campfire)
    - Induction Furnace (Machine Frame + components)
    - Propane Generator (Machine Frame + components)
    - Pressure Cooker (Machine Frame + components)
    - Filler (Machine Frame + components)
```

### Refinery to Asphalt Path

```
1. Find Crude Oil in world → Collect with bucket
2. Mine Coal
3. Place in Refinery:
   - Slot 0: Coal
   - Slot 1: Crude Oil Bucket

4. Outputs (all at once):
   - Propane (slot 2)
   - Gasoline (slot 3)
   - Diesel (slot 4)
   - Asphalt (slot 5)

5. Use Asphalt:
   - Craft Asphalt Blocks
   - Craft Asphalt Slabs
   - Craft Asphalt Stairs
```

### Aqualith Equipment Path

```
1. Travel to Desert biome
2. Find Aqualith Ore (Y: 0-150, very rare)
3. Mine with Diamond Pickaxe → Get Aqualith gems
4. Craft:
   - Aqualith Helmet
   - Aqualith Chestplate
   - Aqualith Leggings
   - Aqualith Boots
   - Aqualith Pickaxe
   - Aqualith Axe
   - Aqualith Sword
   - Aqualith Shovel
   - Aqualith Hoe

Result: Best equipment set in the mod (1741 durability, 14 efficiency, 56 enchantability)
```

### Titanium Armor Path

```
1. Mine Ilmenite Ore (Y: -64 to 16)
2. Smelt → Titanium Ingot
3. Create Steel Ingots (see Machine Production Path)
```
