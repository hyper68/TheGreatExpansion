# The Great Expansion

A Minecraft mod by Hyper Mods that expands the game with new ores, items, and crafting recipes.

## Features

- **New Ores**: Bauxite, Cassiterite, and more
- **Expanded Crafting**: New items and recipes
- **Custom Tools**: Enhanced equipment
- **Balanced Gameplay**: Carefully designed mechanics

## GitHub Pages

This repository includes a GitHub Pages website showcasing Hyper Mods modding studio!

### Enable GitHub Pages

To view the website:

1. Go to **Settings** → **Pages** in this repository
2. Under **Source**, select your branch (e.g., `main` or current branch)
3. Select `/docs` as the folder
4. Click **Save**

The site will be available at: `https://hyper68.github.io/TheGreatExpansion/`

## Development

This mod is built using MCreator for Minecraft modding.

### Building

```bash
./gradlew build
```
