## 📖 Overview

Welcome to **The Great Expansion v0.5.0 Pre-Release 1** - a comprehensive mod that transforms Minecraft with **278 unique content elements** spanning mining, automation, exploration, and building! ## ✨ What's New - Complete Feature List

### 🪨 **Ores & Mining Resources** (8 New Ores)

Transform your mining experience with strategically placed ore types across different Y-levels and biomes!

#### **Standard Ores (Furnace Smelting)**
- **Bauxite** → Aluminum Ingot
  - Y-Level: -16 to 128
  - 7 veins per chunk, 9 ore per vein
  - Requires Iron Pickaxe
  - Essential for machine crafting

- **Cassiterite Ore** → Tin Ingot
  - Y-Level: -32 to 96
  - 6 veins per chunk, 7 ore per vein
  - Used in alloys and components

- **Galena Ore** → Lead Ingot
  - Y-Level: -48 to 48
  - 4 veins per chunk, 6 ore per vein
  - Craft lead arrows for combat

- **Cinnabar Ore** → Mercury Ingot
  - Y-Level: -64 to -8 (Deep ore!)
  - 3 veins per chunk, 4 ore per vein
  - Requires Diamond Pickaxe
  - Rare resource for advanced recipes

- **Ilmenite Ore** → Titanium Ingot
  - Y-Level: -64 to 16
  - 2 veins per chunk, 5 ore per vein
  - High-tier armor and tool material

#### **Legendary Biome-Exclusive Ores**
- **Aqualith Ore** 💎
  - **Desert Biome ONLY** (Y: 0-150)
  - Requires Diamond Pickaxe
  - Hardness: 12.0 (extremely tough!)
  - Drops Aqualith gem directly (no smelting)
  - Creates the most powerful tools and armor in the mod
  - 3 veins per chunk, 2 ore per vein

- **Cryonite Ore** ❄️
  - **Permafrost blocks ONLY** (Winter biomes)
  - Y-Level: 0-64
  - Abundant: 10 veins per chunk, 16 ore per vein
  - No tool requirement
  - Essential for winter-themed crafting

- **Permafrost Iron Ore** ⛏️
  - Special iron variant found in permafrost
  - Smeltable to regular iron

## 🔄 **Complete Crafting & Progression Chains**

### **Steel Production Line** 🏭
```
1. Mine Iron Ore + Get Charcoal
2. Crusher: Iron + Charcoal → Steel Powder
3. Blast Furnace: Steel Powder → Steel Ingot
4. Craft Machine Frame: Steel Frame + Aluminum Ingot
5. Use Machine Frame in all machine recipes
```

### **Silicon Technology Chain** 💿
```
1. Gather Sand → Smelt to Glass
2. Crusher: Glass → Silicon Dust
3. Furnace: Silicon Dust → Silicon Ingot
4. Craft: Silicon Ingot → Silicon Sheet
5. Craft Silicon Sheets → Silicon Padding Armor Components
```

### **Fuel Processing System** ⛽
```
1. Find Crude Oil (fluid)
2. Refinery: Crude Oil + Coal → Propane + Gasoline + Diesel + Asphalt
3. Fill Propane Tank with Propane
4. Propane Generator: Propane → Forge Energy (FE)
5. Power Induction Furnace and other machines with FE
```

### **Aqualith Legendary Gear** 💎
```
1. Explore Desert biomes
2. Mine Aqualith Ore (requires Diamond Pickaxe, very rare)
3. Receive Aqualith gems directly
4. Craft complete tool set (5 tools)
5. Craft complete armor set (4 pieces)
6. Dominate with legendary gear!
```

### **Winter Exploration Path** ❄️
```
1. Find Snowscape/Wild Tundra biomes
2. Mine abundant Cryonite Ore from Permafrost
3. Find Permafrost Iron Ore
4. Gather winter plants (Winterberry, Snowdrop, etc.)
5. Trade with Eskimo villagers
6. Battle Sub-Zombies for loot
7. Craft winter-themed items
```

### **Sky Dimension Journey** ☁️
```
1. Craft Sky Catalyst (late-game recipe)
2. Activate portal to The Skylands
3. Harvest Skywood trees
4. Collect SkyBerries and sky plants
5. Gather Skylarium Gems and Skyshards
6. Find Sky Shrines (3 tiers)
7. Bring resources back for advanced crafting
```

## 🔧 **Technical Information**

### **Requirements:**
- **Minecraft Version:** 1.21.1
- **Mod Loader:** NeoForge 21.1.190 or higher
- **Java Version:** Java 21
- **Optional:** JEI (Just Enough Items) for recipe viewing

### **Installation:**
1. Install NeoForge 21.1.190+ for Minecraft 1.21.1
2. Download The Great Expansion v0.5.0 Pre-Release 1
3. Place the .jar file in your `mods` folder
4. Launch Minecraft with the NeoForge profile
5. Enjoy!

### **Compatibility:**
- ✅ JEI/REI Support (recipe viewing)
- ✅ World Generation Mods (biomes blend naturally)
- ✅ Forge Energy (power integration)
- ✅ Most tech/exploration mods

### **World Generation:**
- ⚠️ **Best on New Worlds** - Full ore generation and biomes
- ✅ **Existing Worlds** - New chunks will generate correctly
- 💡 **Tip:** Explore beyond loaded chunks for new biomes and ores
