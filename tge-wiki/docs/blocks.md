# Blocks & Building Materials

Complete guide to decorative and functional blocks for construction.

## 🧱 Building Blocks

### Asphalt
- **Variants:** Blocks, Slabs, Stairs
- **Uses:** Roads, modern builds
- **Crafting:** Special recipe

### Ice Blocks & Bricks
- **Ice Block** - Natural ice
- **Ice Bricks** - Processed in Ice Cutter
- **Variants:** Slabs, stairs, walls, doors, fences

### Packed Sand
- **Packed Sand** - Compressed sand blocks
- **Packed Sand Bricks** - Decorative variant
- **Variants:** Stairs, slabs

## 🏛️ Decorative Elements

### Pillars (Multiple Materials)
- **Cobblestone Pillars** - Classic stone look
- **Types:** Base, Column, Topper, T-Section
- **Connections:** 3-way, 4-way, Side pillars

### Steel Structures
- **Steel Beams** - Industrial look
- **Steel Frame** - Machine components
- **Steel Face Plate** - Decorative panels
