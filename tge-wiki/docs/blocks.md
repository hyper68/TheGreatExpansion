# Blocks

The Great Expansion adds various building and functional blocks.

## Building Blocks

### Asphalt
**Asphalt** is a building material with variants.

#### Variants
- Asphalt Block
- Asphalt Slabs
- Asphalt Stairs

#### Properties
- Hardness: Moderate
- Blast resistance: Moderate
- Tool: Pickaxe

---

### Ice Blocks
Ice-based building materials processed from regular ice.

#### Variants
- Ice Block
- Ice Bricks
- Ice Brick Slabs
- Ice Brick Stairs
- Ice Brick Walls
- Ice Block Door
- Ice Block Fence
- Ice Block Fence Gate
- Ice Block Trapdoor

#### Processing
Ice blocks are cut into bricks using an Ice Cutter.

---

### Packed Sand
Compressed sand blocks for construction.

#### Variants
- Packed Sand Block
- Packed Sand Bricks
- Packed Sand Stairs
- Packed Sand Brick Stairs

---

### Palo Wood
Complete wood set from Palo Trees.

#### Variants

- Palo Planks
- Palo Slabs
- Palo Stairs
- Palo Fence
- Palo Fence Gate

## Functional Blocks

### Machine Components
- Machine Frame (crafting ingredient)
- Reinforced Permafrost (strong block)

### Storage
- Reinforced Chest (explosion-resistant, 54 slots)

### Fluid Storage
- Water Tank (16,000 mB capacity)
- Propane Tank (fuel storage)

---

## Properties

### Block Hardness
Most blocks follow standard Minecraft hardness values:
- Wood blocks: 2.0
- Stone blocks: 1.5-2.0
- Metal blocks: 5.0
- Ice blocks: 0.5

### Blast Resistance
- Standard blocks: 6.0-10.0
- Reinforced blocks: Higher resistance
- Ice blocks: 3.0
