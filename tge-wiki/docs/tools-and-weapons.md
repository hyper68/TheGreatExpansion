# Tools and Weapons

The Great Expansion adds several tool sets and special tools to Minecraft.

## Tool Sets

### Aqualith Tools
**Aqualith tools** are crafted from Aqualith gems and represent one of the highest-tier tool sets in the mod.

#### Properties
- Durability: 1741 uses
- Mining speed (Efficiency): 14.0
- Attack damage: 16.0 (all tools)
- Attack speed: 12.0
- Enchantability: 56
- Mining level: Diamond
- Repair material: Aqualith

#### Tools in Set
- Aqualith Pickaxe
- Aqualith Axe
- Aqualith Sword
- Aqualith Shovel
- Aqualith Hoe

---

### Titanium Tools
**Titanium tools** are crafted from Titanium Ingots.

#### Titanium Sword
- Durability: 100 uses
- Attack damage: 8.5
- Attack speed: 1.6 (1.0 base + 0.6 modifier)
- Enchantability: 2
- Mining speed: 4.0
- Repair material: Titanium Ingot

#### Titanium Axe
Similar properties to the Titanium Sword, optimized for chopping wood.

---

## Special Tools

### Hammers
**Hammers** are special mining tools that break a 3×3 area of blocks.

#### Diamond Hammer
- Durability: 1561 uses
- Attack damage: 4.0
- Attack speed: 1.4
- Mining speed: 8.0
- Enchantability: 10
- Mining level: Diamond
- Repair material: Diamond
- Special: Breaks 3×3 area

#### Iron Hammer
- Durability: 250 uses
- Attack damage: 4.0
- Attack speed: 1.4
- Mining speed: 8.0
- Enchantability: 4
- Mining level: Iron
- Repair material: Iron Ingot
- Special: Breaks 3×3 area

#### Steel Hammer
- Durability: 1000 uses
- Attack damage: 4.0
- Attack speed: 1.4
- Mining speed: 8.0
- Enchantability: 4
- Mining level: Diamond
- Repair material: Steel Ingot
- Special: Breaks 3×3 area

## Obtaining

### Crafting
All tools follow standard Minecraft tool crafting patterns:
- Pickaxes: 3 material + 2 sticks
- Axes: 3 material + 2 sticks
- Swords: 2 material + 1 stick
- Shovels: 1 material + 2 sticks
- Hoes: 2 material + 2 sticks
- Hammers: 5-6 material + 2 sticks

### Materials
- **Aqualith**: Obtained from mining Aqualith Ore underwater
- **Titanium Ingot**: Smelted from Ilmenite Ore
- **Steel Ingot**: Crafted using Induction Furnace
- **Lead Ingot**: Smelted from Galena Ore

---

## Usage

### Hammers
Hammers function like pickaxes but break a 3×3 area of blocks with each use. They consume 1 durability per block broken, making them efficient for mining large areas.

### Aqualith Tools
Aqualith tools have the highest enchantability (56), making them excellent candidates for high-level enchantments.

## Data Values

Tool IDs use the namespace `the_great_expansion:` followed by the tool name.

Examples:
- `the_great_expansion:aqualith_sword`
- `the_great_expansion:titanium_sword`
- `the_great_expansion:diamond_hammer`
