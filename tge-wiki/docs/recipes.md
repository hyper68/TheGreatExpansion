# Recipe Guides

Complete crafting chains and processing guides.

## 🔨 Crafting Chains

### Steel Production Chain
```
Iron Ore
  → Smelt → Iron Ingot
  → Craft with Coal → Steel Powder
  → Induction Furnace → Steel Ingot
  → Various Steel Items
```

### Aluminum Processing
```
Bauxite Ore
  → Mine → Bauxite
  → Furnace → Aluminum Ingot
  → Craft → Aluminum Items
```

### Titanium Chain
```
Ilmenite Ore
  → Mine → Ilmenite Ore
  → Furnace → Titanium Ingot
  → Craft → Titanium Tools/Armor
```

---

## ⚗️ Processing Methods

### Ore Doubling
```
Ore Block
  → Crusher → 2x Dust
  → Furnace → 2x Ingot
```

### Oil Refining
```
Crude Oil
  → Refinery → Gasoline
  → Refinery → Diesel
  → Refinery → Propane
```

## 💡 Recipe Tips

1. Use JEI/REI in-game for exact recipes
2. Some recipes require specific machines
3. Check machine GUI for special recipes
4. Crushing before smelting doubles output
