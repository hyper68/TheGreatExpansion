# Guides

Advanced information and strategies for The Great Expansion.

## Ore Processing Efficiency

### Maximizing Yield
Use the Crusher before smelting:
- Direct smelting: 100% yield
- Crusher method: 200% yield
- Efficiency gain: 100%

### Automation
Set up processing chains:
1. Input: Chest with ores
2. Crusher processes to dust
3. Furnace/Induction Furnace smelts
4. Output: Chest collects ingots

---

## Power Management

### Generator Setup
1. Build Propane Generator or Lavaleer
2. Connect to machines via cables
3. Monitor power consumption
4. Add energy storage if needed

### Energy Requirements
Most machines require:
- Capacity: 400,000 FE
- Input/Output: 200 FE/tick

## Resource Gathering

### Ore Mining
Efficient mining by Y-level:
- Bauxite: -16 to 128 (common)
- Deep ores: Below Y=0
- Frozen biome ores: Surface to underground

### Special Resources
- Aqualith: Ocean floor exploration
- Ilmenite: Deep mining (rare)
- Permafrost Iron: Frozen biome surface
