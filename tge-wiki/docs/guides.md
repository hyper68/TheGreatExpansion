# Tips & Tricks

Advanced strategies and helpful tips for mastering The Great Expansion.

## ⚡ Efficiency Tips

### Mining
1. **Use Fortune III** on gem ores (Aqualith, Cryonite)
2. **Crush before smelting** for 2x ore output
3. **Build multiple crushers** for parallel processing
4. **Explore frozen biomes** for abundant Permafrost Iron

### Power Generation
1. **Centralize generators** in one power room
2. **Use energy storage** to prevent waste
3. **Propane is portable** - great for remote operations
4. **Lava is renewable** with lava farms

### Automation
1. **Start simple** - single machine chains first
2. **Buffer with chests** between machines
3. **Use hoppers** for automatic item transfer
4. **Plan expansion space** from the beginning

## 🔬 Advanced Techniques

### Ore Multiplication
```
1 Ore → Crusher → 2 Dust
2 Dust → Furnace → 2 Ingots
= 200% yield!
```

### Power Loop
```
Refinery produces Propane
→ Propane Generator
→ Powers Refinery
= Sustainable power
```

### Material Loops

- Crops → Germination Tank → More Crops
