## 🛠️ Tool Sets Overview

The Great Expansion adds several complete tool sets, each with unique properties and uses.

### Available Tool Sets
- **Aqualith Tools** - Water-based, aquatic advantage
- **Titanium Tools** - High durability, strong performance
- **Steel Tools** - Balanced, efficient mining

### Tool Types Per Set
Each complete set includes:
- ⛏️ **Pickaxe** - Mining stone and ores
- 🪓 **Axe** - Chopping wood
- 🔪 **Sword** - Combat weapon
- 🌾 **Hoe** - Farming tool
- ⛏️ **Shovel** - Digging dirt, gravel, sand

## ⚡ Titanium Tools
**End-game tools with exceptional performance**

### Stats
- **Durability:** 2,000+ uses
- **Efficiency:** 9.0
- **Attack Damage:** +4 (Sword: 8 total)
- **Enchantability:** 15

### Special Properties
- 💪 **High Strength** - Increased attack power
- ⚡ **Fast Mining** - Quick block breaking
- 🛡️ **Durable** - Long-lasting tools
- ✨ **Better Enchantments** - Higher enchantment levels

### Crafting Requirements
**Material:** Titanium Ingot (from Ilmenite Ore)

**Recipes:**
```
Titanium Sword:
    [ ]    [Titanium]     [ ]
    [ ]    [Titanium]     [ ]
    [ ]    [ Stick  ]     [ ]

Titanium Axe:
[Titanium] [Titanium]     [ ]
[Titanium] [ Stick  ]     [ ]
    [ ]    [ Stick  ]     [ ]
```

### Best Uses
- **End-Game Mining** - Fastest mining speed
- **Boss Battles** - High damage output
- **Ore Mining** - Efficiency for rare ores
- **Heavy Combat** - Maximum melee damage

### Acquisition
1. Mine Ilmenite Ore (rare, deep underground)
2. Smelt into Titanium Ingots
3. Craft tools at crafting table
4. Enchant for maximum power

### Tips
- Expensive but worth it for end-game
- Use Mending to preserve durability
- Apply Efficiency V for incredible mining speed
- Sharpness V makes titanium sword devastating

## 🔨 Special Tools

### 💎 Diamond Hammer
**Special mining tool for breaking multiple blocks**

**Stats:**
- **Durability:** 1,561 uses
- **Mining Speed:** Moderate
- **Special:** 3x3 area mining

**Crafting:**
```
[Diamond] [Diamond] [Diamond]
[Diamond] [ Stick ] [Diamond]
    [ ]   [ Stick ]     [ ]
```

**Function:**
- Mines in 3x3 area
- Breaks 9 blocks at once
- Great for tunneling
- Efficiency enchantment affects all blocks

**Best For:**
- Creating large tunnels
- Strip mining operations
- Clearing big areas
- Fast resource gathering

**Tips:**
- Use with Efficiency enchantment
- Durability cost per 9 blocks is same as 1
- Perfect for quarry operations
- Combine with Haste potion

## 💡 Usage Tips

### Early Game (Iron Age)
1. Start with **vanilla iron tools**
2. Craft an **Iron Hammer** for efficient mining
3. Save diamonds for important enchants
4. Look for Aqualith if near ocean

### Mid Game (Material Gathering)
1. Build **Steel Hammer** for better mining
2. Create **Aqualith set** if you have ocean access
3. Start gathering **Titanium ore**
4. Enchant your best tools

### Late Game (End Game)
1. Craft full **Titanium tool set**
2. Max enchant everything
3. Keep **specialized tools** (hammers, special picks)
4. Have backup tools with Mending

### Efficiency Tips
1. **Right Tool, Right Job** - Use appropriate tools
2. **Enchant Wisely** - Fortune for ores, Silk Touch for blocks
3. **Backup Tools** - Always have spare
4. **Mending Setup** - XP farm for repairs
5. **Organized Storage** - Keep tools accessible

### Combat Tips
1. **Titanium Sword** for maximum damage
2. **Lead Arrows** for ranged combat
3. **Strength Potions** for boss fights
4. **Enchanted Armor** for protection
5. **Totems** as backup safety
