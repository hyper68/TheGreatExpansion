## 🏭 Machine Overview

The Great Expansion features a robust machine system for processing, power generation, and automation.

### Machine Tiers
- **Tier 1 (Basic):** Crusher, Ice Cutter, Jewlery Workbench
- **Tier 2 (Advanced):** Refinery, Germination Tank, Pressure Cooker
- **Tier 3 (Industrial):** Induction Furnace, Propane Generator, Filler

### Power Requirements
Most machines require:
- **Energy:** FE (Forge Energy) system
- **OR Fuel:** Coal, propane, or other combustibles
- **OR Manual:** Some machines work without power

## ⚙️ Processing Machines

### 🔨 Crusher
**Doubles your ore output by crushing blocks into dust**

**Crafting Recipe:**
```
[ Iron Ingot ] [ Iron Ingot ] [ Iron Ingot ]
[ Iron Ingot ] [   Piston   ] [ Iron Ingot ]
[ Iron Ingot ] [  Redstone  ] [ Iron Ingot ]
```

**Function:**
- Crushes ore blocks into 2x dust
- Processes materials into powder
- Required for many advanced recipes

**Power:** Internal buffer, charges over time

**Usage:**
1. Place Crusher in your base
2. Right-click to open GUI
3. Insert ores in input slot
4. Wait for processing
5. Collect output from result slot

**Processing Time:** ~10 seconds per item

**Recipes:**
- Ore Block → 2x Dust/Powder
- Cobblestone → Gravel
- Gravel → Sand
- Sand → Silicon Dust

**Tips:**
- Build multiple crushers for parallel processing
- Keep powered for faster operation
- Essential for maximizing ore yield

### 🛢️ Refinery
**Processes crude oil into useful fuels**

**Crafting Recipe:**
```
[ Steel Frame ] [ Steel Beams ] [ Steel Frame ]
[Machine Frame] [    Tank     ] [Machine Frame]
[ Steel Beams ] [  Redstone   ] [ Steel Beams ]
```

**Function:**
- Refines Crude Oil into fuels
- Produces Gasoline, Diesel, Propane
- Essential for fuel-based power

**Input:** Crude Oil (from underground pockets)

**Outputs:**
- **Gasoline:** Vehicle fuel, generators
- **Diesel:** High-efficiency fuel
- **Propane:** Portable fuel tanks

**Processing:**
1. Extract Crude Oil from underground
2. Place in Refinery input tank
3. Process using power
4. Collect refined fuels from output

**Automation Tips:**
- Connect to fluid pipes
- Auto-output to storage tanks
- Link to generators for power loop

## ⚡ Power Generation

### 🔋 Propane Generator
**Portable power from propane fuel**

**Crafting Recipe:**
```
[ Steel Frame ] [ Steel Frame ] [ Steel Frame ]
[Machine Frame] [   Furnace   ] [Machine Frame]
[ Steel Beams ] [  Redstone   ] [ Steel Beams ]
```

**Function:**
- Burns propane for FE power
- Portable power source
- Moderate output
- Compact size

**Fuel:** Filled Propane Tank

**Output:** 40 FE/tick (variable based on config)

**Features:**
- Power gauge display
- Fuel level indicator
- Auto-shutoff when full
- Can connect to multiple machines

**Usage:**
1. Craft Propane Generator
2. Fill Propane Tanks at Refinery
3. Insert tank into generator
4. Connect machines via cables
5. Monitor power output

**Efficiency:**
- 1 Propane Tank → ~100,000 FE
- Good for small-medium operations
- Easy to refuel
- Transportable power

## 💡 Automation Tips

### Efficiency
1. **Parallel Processing** - Multiple machines > faster machines
2. **Buffer Storage** - Prevent bottlenecks
3. **Smart Routing** - Send items to right machines
4. **Power Management** - Match generation to consumption

### Layout Planning
1. **Centralized Power** - Generators in one area
2. **Production Lines** - Sequential machine placement
3. **Storage Hub** - Central sorting and storage
4. **Expansion Space** - Plan for growth

### Optimization
1. **Upgrade Machines** - Better tiers process faster
2. **Automate Fuel** - Don't manually refuel
3. **Monitor Gauges** - Watch for issues
4. **Modular Design** - Easy to expand/modify

### Common Setups

**Ore Processing Line:**
```
Ore Input → Crusher → Furnace → Storage
         ↓
    Power Supply
```

**Fuel Production:**
```
Oil Extraction → Refinery → Fuel Tanks → Generators
                              ↓
                         Power Network
```

**Farming Station:**
```
Germination Tank → Auto-Harvest → Storage
         ↓
    Water Tank + Power
```
