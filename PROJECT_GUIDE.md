# The Great Expansion - Project Audit & Guide

This document provides an overview of how the "The Great Expansion" mod project is structured and how its various components link together. This is an **MCreator** project using **NeoForge**.

For a detailed guide on how items link together through gameplay (crafting, progression, and processing), see **[MOD_CONTENT_GUIDE.md](MOD_CONTENT_GUIDE.md)**.

---

## 1. Core Project Files

*   **`the_great_expansion.mcreator`**: The primary project file for MCreator. It contains the registry names, types, and metadata for every mod element. If you want to see a high-level list of all features, this is the place to look.
*   **`elements/`**: Contains `.mod.json` files for every element created in MCreator. Each file defines the configuration for a specific item, block, procedure, etc.
    *   Example: `elements/DiamondHammer.mod.json` defines the Diamond Hammer tool.

---

## 2. Java Code Structure (`src/main/java/net/mcreator/thegreatexpansion/`)

The Java code is automatically generated by MCreator but can be manually edited if "Locked Code" is enabled for an element.

*   **`TheGreatExpansionMod.java`**: The main mod class. It handles mod setup and registers all registry objects.
*   **`init/`**: Contains "Registry" classes that link Java objects to Minecraft's registry system.
    *   `TheGreatExpansionModItems.java`: Every item in the mod is registered here.
    *   `TheGreatExpansionModBlocks.java`: Every block in the mod is registered here.
    *   `TheGreatExpansionModTabs.java`: Defines custom Creative Mode tabs.
    *   `TheGreatExpansionModProcedures.java`: Links procedures to events (if applicable).
*   **`procedures/`**: Contains the logic for MCreator "Procedures" (visual scripts converted to Java).
    *   Example: `SteelHammerBlockDestroyedWithToolProcedure.java`.
*   **`block/`, `item/`, `entity/`, `fluid/`, `potion/`**: Contain the actual implementation classes for specific mod elements.
    *   Example: `block/BauxiteBlock.java`.

---

## 3. Resources & Data (`src/main/resources/`)

### Assets (`assets/the_great_expansion/`)
These files handle the visual and client-side aspects of the mod.
*   **`textures/`**: PNG images for items, blocks, and entities.
*   **`models/`**: JSON files defining the 3D shape of items and blocks.
*   **`blockstates/`**: JSON files mapping block states to models.
*   **`lang/en_us.json`**: Localization file containing all display names.
*   **`sounds.json`**: Registry for custom sounds.

### Data (`data/the_great_expansion/`)
These files handle the server-side logic and world generation.
*   **`recipe/`**: JSON files for crafting, smelting, etc.
*   **`loot_table/`**: Defines what items drop from blocks or entities.
*   **`worldgen/`**: Contains configuration for biomes, features (ores), and structures.
*   **`tags/`**: Groups items or blocks together (e.g., `#minecraft:pickaxe_mineable`).

## 4. How Elements Link Together (Example: Bauxite Ore)

To understand how a single element like **Bauxite** works, you can follow these links:

1.  **Definition**: `elements/Bauxite.mod.json` (MCreator settings).
2.  **Registry**: `src/main/java/net/mcreator/thegreatexpansion/init/TheGreatExpansionModBlocks.java` (registers the block).
3.  **Implementation**: `src/main/java/net/mcreator/thegreatexpansion/block/BauxiteBlock.java` (Java logic).
4.  **Visuals**:
    *   `src/main/resources/assets/the_great_expansion/blockstates/bauxite.json`
    *   `src/main/resources/assets/the_great_expansion/models/block/bauxite.json`
    *   `src/main/resources/assets/the_great_expansion/textures/block/bauxite.png` (path defined in model)
5.  **Drops**: `src/main/resources/data/the_great_expansion/loot_table/blocks/bauxite.json`.
6.  **World Gen**:
    *   `src/main/resources/data/the_great_expansion/worldgen/configured_feature/bauxite.json`
    *   `src/main/resources/data/the_great_expansion/worldgen/placed_feature/bauxite.json`
7.  **Name**: `src/main/resources/assets/the_great_expansion/lang/en_us.json` (search for `block.the_great_expansion.bauxite`).

---

## 5. Other Folders

*   **`models/` (Root)**: Contains raw models (e.g., `.java`, `.obj`, `.gltf`) used during development or for entities.
*   **`src/main/ski-resort-tycoon/`**: A separate React + Vite project. This is **not** part of the Minecraft mod but appears to be a web-based companion or a separate tool entirely.

---

## 6. Tips for Navigation

*   **Finding a Name**: Use global search (Ctrl+Shift+F) to search for the "registry name" (e.g., `diamond_hammer`) to find all related files.
*   **Checking Recipes**: Look in `src/main/resources/data/the_great_expansion/recipe/`. They are named after the element they produce.
*   **Debugging Logic**: Check the `procedures/` folder if something happens when you interact with a block or item.
